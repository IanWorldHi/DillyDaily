# DillyDaily
Youre daily dilly tracker tracking your favourite dailies such as wordle, krillion, timeguessr and more!

- can add "permissions": ["activeTab"] if want temp access to website they on (read url, inject script css)










## Development

1. `npm install`
2. `npm run build`, or `npm run watch` to rebuild on every save
3. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and pick the `dist/` folder
4. After a rebuild, close and reopen the popup to see your changes. Changes to `public/manifest.json` need the reload button on `chrome://extensions`
